## Deploy on Railway

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/chatgpt-ui)

One-click deploy of the official client, web-server and wsgi-server images with PostgreSQL. A random Django `SECRET_KEY` and admin password (variable `DJANGO_SUPERUSER_PASSWORD` on `backend-wsgi-server`) are generated per deployment and open registration is off; sign in at `/admin` on the backend domain and set `openai_api_key` under Chat → Settings.
